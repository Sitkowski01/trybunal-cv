# Junior Java Developer — FinPay Systems

(Oferta fikcyjna — przykład do ewaluacji Trybunału CV.)

FinPay Systems rozwija platformę płatności online i rozliczeń dla sklepów internetowych.
Szukamy osoby na stanowisko Junior Java Developera do zespołu rozliczeń transakcji.

## Obowiązki
- Rozwój mikroserwisów rozliczeniowych w Javie i Spring Boot.
- Projektowanie i utrzymanie REST API dla partnerów.
- Pisanie testów jednostkowych i integracyjnych.
- Praca z bazą PostgreSQL: zapytania, migracje, optymalizacja prostych zapytań.

## Wymagania
- Znajomość Javy (17 lub nowszej) i programowania obiektowego.
- Podstawy Spring Boot (REST, Spring Data JPA).
- Znajomość SQL, najlepiej PostgreSQL.
- Pisanie testów w JUnit 5 (Mockito to plus).
- Praca z Gitem.
- Co najmniej jeden projekt (komercyjny, stażowy lub własny) pokazujący powyższe umiejętności.

## Mile widziane
- Docker, Testcontainers.
- Kafka lub inny broker wiadomości.
- Zainteresowanie finansami, płatnościami lub księgowością.
- Angielski na poziomie B2.

## Oferujemy
Umowa o pracę, mentoring seniora, praca hybrydowa (Warszawa).
