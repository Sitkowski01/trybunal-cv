# DevOps Engineer (Mid) — ChmuraTech

(Oferta fikcyjna — przykład do ewaluacji Trybunału CV.)

ChmuraTech utrzymuje infrastrukturę chmurową dla kilkunastu klientów SaaS.
Szukamy DevOps Engineera z 2–4 latami doświadczenia.

## Obowiązki
- Utrzymanie i rozwój infrastruktury w AWS jako kod (Terraform).
- Zarządzanie klastrami Kubernetes (EKS) i wdrożeniami aplikacji.
- Budowa i utrzymanie pipeline'ów CI/CD.
- Monitoring, alerty i udział w dyżurach.

## Wymagania
- 2–4 lata doświadczenia na stanowisku DevOps, SRE lub pokrewnym.
- Praktyczna znajomość AWS (EC2, VPC, IAM, RDS, S3).
- Terraform w codziennej pracy.
- Docker i Kubernetes.
- CI/CD: GitHub Actions lub GitLab CI.
- Dobra znajomość Linuxa i skryptów Bash.
- Monitoring: Prometheus, Grafana.

## Mile widziane
- Helm, Argo CD.
- Python do automatyzacji.
- Certyfikat AWS (np. SysOps Administrator, Solutions Architect).
- Doświadczenie z optymalizacją kosztów chmury.

## Oferujemy
B2B, praca zdalna, dyżury płatne dodatkowo.
