# Senior Frontend Developer (React) — Koszyk24

(Oferta fikcyjna — przykład do ewaluacji Trybunału CV.)

Koszyk24 to platforma e-commerce obsługująca 2 mln klientów miesięcznie.
Szukamy Senior Frontend Developera, który przejmie odpowiedzialność za ścieżkę zakupową.

## Obowiązki
- Rozwój sklepu w React, TypeScript i Next.js.
- Optymalizacja wydajności (Core Web Vitals) i konwersji.
- Współtworzenie design systemu i standardów jakości kodu.
- Mentoring developerów mid i junior, code review.

## Wymagania
- Minimum 5 lat komercyjnego doświadczenia z React.
- Bardzo dobra znajomość TypeScript.
- Doświadczenie z Next.js (SSR/SSG).
- Testy: Jest, React Testing Library, Playwright lub Cypress.
- Doświadczenie w optymalizacji wydajności aplikacji webowych.
- Udokumentowany wpływ na produkt (metryki, wyniki).

## Mile widziane
- Doświadczenie w e-commerce (koszyk, checkout, płatności).
- GraphQL.
- Budowa design systemu (Storybook).
- Testy A/B i praca z danymi produktowymi.

## Oferujemy
B2B lub UoP, praca zdalna, budżet szkoleniowy.
